Pasos:
Abrir terminal ctrl ñ

1. npm install -> Instala las dependencias declaradas en package.json.


2. La carpeta public contiene pages, js, styles y assets.

3. Crear el server.js -> Cargar las rutas (recursos) del proyecto. Para tener el HTML.
Afuera de public, y pegar lo siguiente;

const express = require('express');
const path = require('path');

const app = express();


app.use(express.static(path.join(__dirname, 'public')));


app.get('/', (req, res) => {
    res.sendFile(path.join(__dirname, 'public', 'pages/index.html'));
});

const PORT = 3001;
app.listen(PORT, () => {
    console.log(`Servidor corriendo en http://localhost:${PORT}`);
});


4. Scripts disponibles en package.json:
    "start": "node server.js",
    "dev": "nodemon server.js",
    "api": "json-server --watch db.json --port 3005"
Estas dos líneas le indican al servidor como comportarse, con que comando ejecturtarse y que archivo ejecutar

5. No instalar dependencias globalmente. npm install prepara Express, nodemon y json-server desde package.json.


6. Probar en dos terminales:

Terminal 1: npm run api
API: http://localhost:3005

Terminal 2: npm start
Frontend: http://localhost:3001
